Brainfuck algorithms

This page presents a collection of Brainfuck algorithms from the BF-examples repository.

The examples cover arithmetic, comparisons, memory manipulation, conversions, string manipulation, and other useful operations written in Brainfuck.

Repository: programming12321/BF-examples

1. Arithmetic

1.1 Addition

Adds two values together.

File: add.bf 

[->+<]>[<+>-]

1.2 Subtraction

Subtracts one cell from another.

File: sub.bf 

[>-<-]>

1.3 Multiplication

Multiplies two values.

File: mul.bf 

[>[>+>+<<-]>[<+>-]<-]

1.4 Division

Computes integer division using Brainfuck cells.

File: div.bf 

[->-[>+>>]>[+[-<+>]>+>>]<<<<<]

1.5 Modulo

Computes the remainder of an integer division.

File: mod.bf 

[>->+<<]>[<+>-]<

2. Comparisons

2.1 Greater than

Tests whether one value is greater than another. The result is represented as a boolean value.

File: gt.bf 

[>-<-]>[<+>-]

2.2 Greater than or equal

Tests whether one value is greater than or equal to another.

File: gte.bf 

[>-<-]>[<+>-]>[-<+>]

3. Memory manipulation

3.1 Duplicate

Duplicates a value into another cell while preserving the original.

File: duplic.bf 

[>+>+<<-]>>[<<+>>-]<

3.2 Swap

Swaps the values of two cells.

File: swap.bf 

[>+<-]>[<+>-]
