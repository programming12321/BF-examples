Brainfuck algorithms

This page presents a collection of Brainfuck algorithms from the BF-examples repository.

The examples cover arithmetic, comparisons, logic gates, memory manipulation, conversions, string manipulation, and other useful operations written in Brainfuck.

3. Logic gates

Logic gates operate on boolean values. In these examples, 0 represents false and 1 represents true.

3.1 NOT

Boolean behavior: 0 → 1 and 1 → 0.

File: not.bf 

>+<[->-<]>[-<+>]<

1 0
