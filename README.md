# BF-examples

Welcome to **BF-examples**! 🧠

Explore a collection of **Brainfuck examples, algorithms, and experiments** — from simple programs to advanced mathematical and utility algorithms.

### 📚 What's inside?

* 🔢 Mathematical algorithms
* ➕ Arithmetic operations
* 🔢 Powers and number operations
* 🎲 Pseudo-random number generation
* 🔤 String manipulation
* 🔀 Logic and comparisons
* 🧮 Number and ASCII conversions
* 🛠️ Useful Brainfuck utilities
* 💡 Experimental and compact programs

Some examples include:

* `add.bf` — addition
* `sub.bf` — subtraction
* `mul.bf` — multiplication
* `div.bf` — division
* `mod.bf` — modulo
* `power.bf` — exponentiation
* `rand.bf` — pseudo-random number generation
* `numascii.bf` — number to ASCII conversion
* `asciinum.bf` — ASCII to number conversion

Whether you're learning Brainfuck, experimenting with algorithms, or looking for reusable examples, **BF-examples** is a place to explore and learn.

> **Brainfuck is tiny. The possibilities aren't.**
